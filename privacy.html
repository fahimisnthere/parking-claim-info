Privacy policy

How this app handles data

Effective date: 27 September 2026. This policy describes Parking Claim Automation, a personal-use tool maintained by Fahim (@fahimisnthere).

Information accessed

With the owner's permission, the app searches Gmail for matching Touch ’n Go statement emails and reads their metadata and PDF attachments. Statements may contain the owner's name, card identifiers, transaction dates, locations, amounts and balances.

The app reads the designated Google Sheets claim template and existing claim records, and writes claim dates, descriptions, amounts, formulas and file references. It accesses Drive files created by the app or explicitly made available to it. It uses saved Google authorization credentials to perform these operations.

Purpose and use

Data is used to identify relevant parking transactions, calculate claim totals, prepare statement copies, maintain the claim form and detect duplicate claims. Visual covering of unrelated rows does not remove the underlying PDF content.

The app does not sell Google user data, use it for advertising, or send it to AI services for model training. It does not automatically email statements or submit claims to an employer.

Processing and service providers

The desktop version processes statements on the owner's computer. When the owner enables hosted execution, processing occurs on GitHub Actions runners associated with the private automation repository. Google provides the connected Gmail, Drive and Sheets services; GitHub provides the hosted execution and repository services.

Statements and account credentials are not intended for the public information website or its repository. Anyone the owner grants access to the private automation repository or its workflows may have access according to their permissions. The owner controls sharing of saved Drive files and Sheets.

Storage and retention

Original and prepared statements are saved in the owner's Google Drive. Claim entries, document links and duplicate-detection records are stored in the claim spreadsheet and its metadata. These records remain until the owner deletes them.

The desktop version also keeps downloaded statements, prepared files and authorization on the owner's computer until removed. Hosted execution uses temporary working files; saved authorization is configured through GitHub Actions secrets. Private workflow logs may contain execution results, claim summaries and errors, and are retained according to repository settings.

Access, revocation and deletion

The owner can stop scheduled workflows in GitHub and revoke the app's access through Google Account connections. Revoking access stops future authorized access but does not delete existing files or claims.

To remove stored information, delete the relevant Gmail messages, Drive files, spreadsheet records, local working files, GitHub secrets and workflow logs as applicable. Duplicate-detection records stored in spreadsheet metadata may require separate removal or deletion of the spreadsheet. Provider trash, backups and retention rules may still apply.

Public website

These information pages contain no sign-in form, advertising, analytics scripts or app-added tracking cookies. GitHub Pages hosts the website and may process normal connection information under its own privacy statement.

Google API data

Parking Claim Automation's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and changes

For general privacy questions, contact the maintainer through the project's public issue page. Do not post personal statements, tokens or account details there. Material changes to these practices will be reflected on this page with an updated date.
